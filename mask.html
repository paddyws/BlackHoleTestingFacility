How to use

Paint the structure you want excluded. Ellipse: drag a box around the bar. Polygon: click vertices, then Close polygon. Use Erase to remove your paint.

Scroll to zoom. Pan with the Pan tool or hold Space and drag. Undo reverses a drawing action.

Save stays in this browser. Export the JSON file, then attach it in our chat so I can run the next analysis. Nothing you draw is uploaded automatically.

The old source mask stays intact. Your mask will be added as missing data, never painted black in the scientific image. Large exclusions can leave too little arm coverage.
